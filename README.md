# Zen Bridge static site demo

A test of moving [zenbridge.org](https://www.zenbridge.org) off Weebly onto a static site hosted on GitHub Pages.

- [`current/`](current/) is a snapshot of the live Weebly site, saved on 2026-11-26. `.github/workflows/pages.yml` publishes it to GitHub Pages.
- The Jekyll rebuild of the site is parked on the [`jekyll-parking`](../../tree/jekyll-parking) branch.
